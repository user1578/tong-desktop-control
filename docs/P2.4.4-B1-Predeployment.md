### 写入、审批与重放语义

原固定工具与任务审批格式保持，新增一项调用约束：

| 接口 | `idempotencyKey` 要求 |
| --- | --- |
| `tong_agentdock_file_edit` 正式 add/replace/patch | 必需；16–128 个 ASCII 字母、数字或 `-`，推荐随机 UUID。 |
| `tong_agentdock_file_edit` dryRun | 不要求、不预留 key；正式调用仍需独立授权及全部复检。 |
| `tong_agentdock_command` git_status/git_diff/pytest | 必需，包含只读 Git 命令，防止未知结果的重复启动。 |
| 读取及 session_status/session_cancel | 不接受此参数。 |

操作记录位于本机 policy 同级的 `agentdock-operations/<key的SHA-256>.json`，不得位于任何登记项目内。记录仅含操作/参数摘要 hash、项目/任务/审批引用及时间，不存正文、命令输出或原 key。原子 create-only 预留并 sync；预留后即使批准撤销、断线、结果验证失败或部分生效，也保留记录。相同 key 返回 `REPLAY_DENIED`，不是返回缓存成功；部分请求可能先因内容已变化而被参数校验拒绝，但不会再次正式写入。

该机制是拒绝重复派发，不是 exactly-once 事务。未知结果必须先读取文件、查会话/Git 或由本机操作者对账，不能自动换新 key 重试。独立 taskId 的审批仍可在其期限、操作和精确路径范围内连续执行；taskId 不是只能调用一次的令牌。每次实际操作由 key 限制重放，任务结束时应撤销本机审批。没有网页/MCP 授权配置修改接口；`project.read`、`project.write`、`command.execute` 与 Codex `agent.execute` 相互独立。

add 默认不覆盖，显式 overwrite 还须本机批准；多文件 patch 全部目标预检，拒绝 move/delete/绝对路径/遍历/歧义语法。dry run 后再次检查所有文件身份、批准及目标，正式写后逐文件验证内容 hash。补丁使用登记项目根目录 workdir。后端多文件失败不保证事务回滚；Tong 返回失败/未知影响，保留证据，不自动回滚或重试。

### 固定命令、会话与输出

仅开放 git_status、git_diff、pytest；用户不能传 cmd、env、解释器、任意 args 或另一个 workdir。命令由 Tong 固定模板构造，批准路径使用 PowerShell 单引号转义，Git diff 使用 literal pathspec。解释器位于所有登记项目外并匹配本机 hash。Git 禁止外部 diff/textconv/fsmonitor/配置 include/linked worktree/对象 alternates；pytest 固定入口、禁用自动插件/conftest/addopts，并使用隔离 Python 参数。

**pytest 仍执行项目 Python 代码**。路径和环境检查不阻止被批准代码以 AgentDock 身份访问项目外或网络；exe hash 也不验证所有加载依赖。此轮仅信任本机操作者创建的合成项目。

默认同 policy 进程内最多 8 个启动/运行会话，MCP Router 之间共享；会话 UUID 的拥有者仍是创建它的 Router，绑定项目、任务、审批、根目录和连接代次。跨 Router/项目/任务及旧连接查询、取消被拒绝。命令 timeoutMs 为 100–30000，输出每段上限 64KiB；Tong 会话期限为启动返回时单调时间 + timeoutMs + 5 秒，到期释放容量不等于确认 OS 进程已终止。后端负责超时和进程树取消；Tong 关闭最多等待 10 秒，超限属于尽力清理，需要本机对账。

`toolOk=true` 与实际 `exitCode`/`commandOk` 区分；权限拒绝、AgentDock工具错误、传输中断/超时也分别分类。Gateway 错参数及非白名单工具通过 JSON-RPC `-32602` 拒绝；SDK 表现为异常，不是工具返回的 isError。断线不回退到 Codex、其他后端或本地 Shell。

## 回滚与上线前事项

回滚独立试验只需停止本次 owned 进程、撤销其合成 policy；没有生产切换需要回滚。开发代码回滚可在干净开发分支 `git revert <本次提交>`；开发依赖补丁亦应从锁定版本重新安装并应用对应版本补丁，不能把升级后的 node_modules 复制到生产。证据与合成状态保留在 PoC，可供审查；不提交 Token、SQLite、临时日志或项目产物。

上线前仍需独立授权及验收：

- 路径检查存在检查到 AgentDock写入之间的 TOCTOU窗口。进程内锁不覆盖其他 Tong进程、同账户恶意进程或外部程序；需要 backend/OS原子边界或专用受限账户/隔离环境，才能提升到不可信项目。
- 固定 pytest的批准必须明确包含执行项目代码风险。环境参数收敛不是干净 OS环境，更不是项目沙箱；继续拒绝任意 Shell、stdin执行和动态工具代理。
- 上线使用独立可保护审批/state目录，管理期限、任务撤销、持久操作记录留存及未知结果对账；恢复时不能删除记录后自动重放。UI需展示 key、未知影响、退出码、超时和增量输出语义。
