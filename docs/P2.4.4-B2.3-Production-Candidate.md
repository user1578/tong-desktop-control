### 本机审批与 DACL

唯一正式审批入口是 `TongProductionApproval.ps1 -Mode approve` 的交互 ConsoleHost。要求非重定向输入/输出、实际控制台，并逐字输入含固定根、action、profile/source/release hash 和新随机 nonce 的挑战。普通 CLI `--approved`、环境变量、合成 minting API 都不能批准 production。回执按动作区分 `init/start/stop/enable-agentdock/disable-agentdock/backup/restore/manager`，30 分钟有效，需本机重新审批才能续期。运行启动不等于批准新项目或新执行动作。

启动前从固定已保护的 `D:\agentdock-poc-20261010\isolated\state\b23-production-approvals` 读取密封 bootstrap；未批准前不访问正式实例根。此路径也是正式方案的一部分，不能移动、删掉或换成普通配置文件。manager 回执/pin 与当前 Tong 版本的回执/pin 分开，回滚旧 Tong 仍使用同一经过核验的新 manager。

目录初始化只操作固定批准根及后代，拒绝未知现存数据、非 canonical/空 DACL、外部 Allow SID、非法 owner、junction/reparse/hardlink。生产根在创建时原子设置 protected DACL，仅 Rune 当前 SID、SYSTEM、Administrators；后代继承。新 policy/secret/journal 不覆盖。没有改整个 Tong checkout 的 ACL。
