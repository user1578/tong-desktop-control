## 固定工具接口

仍由 `TONG_AGENTDOCK_ENABLED=1` 在独立开发进程显式启用；默认关闭。URL、Token、policy 配置沿用 P2.4.3。本阶段不添加公网服务或通用 `toolName + arguments` 入口。

原 `tong_agentdock_list_dir/read_file/search_text` 保持原输入与独立工具 grant。

所有新工具要求 `projectId`、`taskId`、`approvalId`。项目 ID 来自 Tong 登记；审批引用是本机 policy 中的记录 ID，本身不构成授权凭据。

| 工具 | 额外输入 | 行为 |
| --- | --- | --- |
| `tong_agentdock_file_edit` | `action=add`：`path,content,overwrite?`；`replace`：`path,old,new,expectedMatches?=1`；`patch`：`patch`；共用 `dryRun?` | 映射 `file_edit`，先 backend dry run，重新核对审批与路径，随后写入并读回比较预期文本；返回相对路径、SHA-256、大小与 verified。 |
| `tong_agentdock_command` | `operation=git_status/git_diff/pytest`、`timeoutMs?=100..30000`、`async?` | Tong 由本机 profile 构造命令；workdir 是经过验证的登记根目录。默认 auto，前台等待 500ms，仍运行则返回 Tong 会话 UUID。 |
| `tong_agentdock_session_status` | `sessionId` | 仅查询同 Router 创建且绑定相同项目、任务、审批的会话；审批仍须有效。 |
| `tong_agentdock_session_cancel` | `sessionId` | 只发送 `session_act action=kill`；不能写 stdin、列出所有会话或 kill_all。已拥有会话的取消不要求审批仍有效。 |

写入只接受项目相对路径和已存在的安全父目录；不会自动创建目录。文本及预期结果上限 64KiB，补丁最多 20 个不同文件。replace 要求恰好一个精确匹配；不接受模糊匹配。patch 仅接受 `*** Begin Patch` / `*** End Patch`，内部允许 `Add File`、`Update File`、无锚点 `@@` 和明确前缀的行。拒绝 unified diff、Delete、Move、绝对路径、重复文件、空/歧义 hunk 和其他语法。换行/BOM按原文件保留。所有补丁目标在任何 backend 调用前逐一验证；只验证 workdir 不足以放行。

默认 add 不覆盖。即使输入 `overwrite=true`，审批也必须含 `allowOverwrite=true`。patch 的 Add 永不覆盖既有文件。dryRun 同样需要独立写审批，且验证没有发生文件变化。

Git diff 只查看本机 `commands.gitDiffPaths` 中逐个获批、可验证的普通文件，通过固定 literal pathspec 传参。Git status 使用项目范围 `.`，显示 tracked 状态，不扫描 untracked。只支持独立 `.git` 目录；拒绝 linked worktree、metadata 链接、config include、commondir、alternates，以及敏感/未知的完整工作树路径。固定关闭 pager、fsmonitor、外部 diff、textconv 和子模块递归，禁用 global/system config。相关参数语义见 [Git diff 官方文档](https://git-scm.com/docs/git-diff)。

pytest 的解释器必须位于所有登记项目外，并匹配本机批准的可执行文件 SHA-256。固定 `-I -B -m pytest -q -p no:cacheprovider -c NUL -o addopts= --noconftest --rootdir=. --confcutdir=.`，最后仅添加批准的 `pytestEntry`；清空 addopts 并关闭插件自动加载。此阶段不支持依赖 conftest 或外部插件的入口。完整项目树须通过链接、硬链接和保护路径检查。配置发现规则参见 [pytest 官方文档](https://pytest.org/en/stable/reference/customize.html)。

## 项目授权与本机审批

授权文件由可信本机操作者直接管理，放在保护目录且不得位于任何登记项目内。Tong 拒绝 policy 的链接、重解析点及硬链接；没有网页/MCP审批修改接口。保留 `schemaVersion=1` 和 P2.4.3 的合成项目 `tools` 格式，追加 `approvals` 与命令 profile，兼容旧只读配置。

- `project.read`：旧项目 `permission=read/write` 加独立 `tools` 列表，等价于持续的逐工具读授权；写权限不由它产生。
- `project.write`：登记 permission 必须为 write，另有下面的任务审批。
- `command.execute`：独立审批及本机 profile；读/写 grant 和 Codex `agent.execute` 都不产生该能力。pytest 批准意味着信任该测试代码在 AgentDock 账户下执行。

示例中的 executable/hash 必须由本机操作者替换为经核对的真实值；不是网页提交项。`backendWorkspaceRoot` 仅用于确定映射 AgentDock 的相对 display 路径，必须与独立实例 `AGENTDOCK_DEFAULT_DIR` 一致，不作为访问许可。

## 结果、会话和审计

命令返回 `toolOk=true` 仅表示工具调用完成；`commandOk=false,exitCode=1` 表示进程失败，`status=timeout,timedOut=true` 表示命令生命周期超时。传输超时则为错误 `TIMEOUT`，不能混为命令超时。stdout/stderr是增量段，`outputMode=delta`，调用方应按会话依次收集；保留退出码及截断标志。每次输出限 64KiB，Client响应另有总字节限额。

错误明确区分 `tong_denied`（PROJECT/APPROVAL/ACCESS/SESSION/EXECUTABLE_DENIED）、`agentdock_error`（TOOL_FAILED）、`transport_error`（UNAVAILABLE/TIMEOUT）、验证/限额错误。写后校验失败返回 VERIFY_FAILED，不宣称成功、不自动回滚或重试。`effect=applied/executed/unknown` 说明已发生或不能确定的影响；连接中断后不盲目重放、不回退到 Codex/本地 Shell。

Router 默认最多 8 个正在启动/已拥有的会话，预留槽跨项目生效。同项目请求串行防止本 Router 自己制造读写竞态。会话 UUID 不是 backend ID；绑定当前 Client 连接代次，重连后拒绝沿用旧句柄，避免错误取消别的实例。会话最长 30秒，Router 关闭时尽力取消自己创建的会话。启动后审批撤销或结果校验失败时尽力 kill；只有确认终止才删除记录，无法确认则错误携带取消句柄与 unknown 状态。进程树取消由 AgentDock 负责；不是 Tong 的 OS 隔离实现。

复用 `runtime/agentdock-audit.jsonl`。记录请求 UUID、项目、固定工具/操作、任务、审批引用、已验证目标、started/commit/finished/cleanup、结果/退出状态、耗时、错误类别和必要内容 hash。不开启参数/正文日志，不保存 Bearer、文件内容、搜索正文或命令 stdout/stderr。执行前审计失败拒绝启动；已启动进程的安全取消仍尽力进行。完成审计失败会返回 AUDIT_UNAVAILABLE，不能把此前写入当作没有发生。

## 安全边界与 P2.4.4-B 建议

Tong 路径检查不是原子的 OS沙箱。恶意同账户进程仍可能在检查/网络调用间替换路径、配置或可执行文件；backend 行为亦需要可信。完整树检查保守拒绝未知/敏感路径，不能用于任意真实仓库。可执行文件hash不验证其全部依赖。固定 pytest仍执行 Python代码，该代码能使用 AgentDock账户访问项目外文件或网络；本阶段仅在操作者确认可信的合成项目执行。

`workdir` 只确定起点，不能隔离进程。Windows当前用户无法可靠限制通用命令影响范围，故继续拒绝任意PowerShell/Shell、stdin写入、动态工具、WSL、插件和ACP。通用执行需要专用受限账户/隔离环境与后端OS边界，不能通过放宽负向测试达成。检查后的本机审批尽量贴近调用，但不能在AgentDock进程内部原子强制其期限；连接中断、Tong崩溃或审计故障仍需对账，并依靠有限命令超时终止未知会话。

P2.4.4-B应另行审查本提交和证据，在获准的独立开发网页/Gateway连接中展示上述四种结果与增量会话输出，验证本机审批不可由网页篡改、项目/任务范围持续生效、期限/撤销与断线对账、默认关闭和现有Codex路线。网页启用只能开放固定接口，不增加公网通用执行面。生产部署、真实项目准入及OS隔离需要独立授权与验收，本阶段不自动开始。
